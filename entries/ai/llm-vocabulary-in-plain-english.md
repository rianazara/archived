From a forward-deployed PM listing the terms nobody defined for them:

- **LLM** — the model that writes the answers.
- **API** — how your code talks to it.
- **Tokens** — how the model counts text, and how you get billed.
- **System prompt** — its job description.
- **Context window** — how much it can see at once.

The framing is the useful bit: you don't need to code to use these, you need
to be able to use them correctly in a sentence. Misusing them is what
signals you've only read about the field.

Two worth internalizing further, because most cost and quality problems
reduce to them: tokens (see [[llm-cost-scales-with-tokens]]) and the context
window, which is the budget everything else competes for.
