Courses, all free, roughly easiest to hardest:

- **Anthropic Academy** — Claude, Claude Code, the API and MCP, with
  certificates. Anthropic also publishes a Claude-focused certification and
  a cookbook of worked examples.
- **Generative AI for Beginners** (Microsoft) — 21 lessons from prompting
  through RAG and agents.
- **Hugging Face Agents Course** — practical agent building, certificate
  included.
- **Hugging Face LLM Course** — what's happening inside the model, past
  prompting.
- **MIT 6.S191** — university-level deep learning, online.

For agent-specific practice, a second post pointed at provider docs
(OpenAI, Hugging Face), DeepLearning.AI short courses, framework docs
(LangChain, LlamaIndex, AutoGen, CrewAI), and places to build — the OpenAI
cookbook, Kaggle, Colab.

The rule attached to that list is the one that matters: don't just study
agents, build them while studying. Which is the same instruction as
[[seven-layers-of-ai-engineering]] — let a project tell you what to learn
next.
