# Briefs

One file per day, `YYYY-MM-DD.md`, written by the `Archived: AI daily brief`
cloud routine and pushed here.

Each brief covers only entries marked `review: true` — the AI learning set —
and contains what's new in that set, three quiz questions drawn from
different areas, the answers, and one cross-topic connection.

These are generated. Don't hand-edit them; the routine never reads them back,
so an edit would just be overwritten conceptually and lost in practice. If a
brief is wrong, the fix belongs in the routine's prompt.

The routine writes only inside this folder. It never touches `entries/`.
